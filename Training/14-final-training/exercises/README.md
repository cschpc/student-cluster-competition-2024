# Mystery benchmark

In this exercise you will be installing two mystery benchmarks from their source code for Lumi.  
Try installing them by yourself first from the source code, and ask for help from the advisor when needed.

## HPCG

Task: Install and run [rocHPCG](https://github.com/ROCm/rocHPCG) on Lumi.  
    1. Run it first on one node, using 2 gpus 
    2. Run it on three nodes, with 2 gpus reserved per node
    3. Change different input variables and aim for a good result (2-4% of theoretical peak)

## BabelStream

Task: Install and run [BabelStream](https://github.com/UoB-HPC/BabelStream) on Lumi.


## Extra: IO500

Try to install the [IO500 benchmark](https://github.com/IO500/io500) for Lumi.  
Run it on just the CPU partition.
