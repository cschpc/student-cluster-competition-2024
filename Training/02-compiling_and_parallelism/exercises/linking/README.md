# Linking exercise

In this folder there are two codes and thus two separate exercises.

## Exercise 1

Try compiling the included C code "basic_dependency.c" with gcc.

The compilation fails because the basic C math library isn't linked.  
Try finding a way to link the math library to the program during compilation and compile it again.  


## Exercise 2 (After modules)

Try compiling the included code "module_linking.cpp" with g++.

A "normal compilation" isn't enough but a dependency needs to be linked.  
Read through the error message to figure out what dependency to include.  

The dependency can be included during compilation with "-l" and via supercomputer modules.
