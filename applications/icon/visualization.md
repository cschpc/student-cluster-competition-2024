# Visualization with ICON

Installing requirements for Python and Jupyter:
```
# Create virtual environment
python3 -m venv icon-visualization
source icon-visualization/bin/activate
pip install -r requirements.txt
```

Starting Jupyter in local workstation:
```
jupyter notebook
```

The Notebook `icon-visualization.ipynb` contains example on reading a set of files into
a single time series and plotting a field on a map
