# Student cluster competition 2024

This repository contains the training materials and other relevant documents for the Finnish team applying to the Student cluster competition at SC23.

## SCC Competition deadlines

|Date|Deadline|
|---|---|
|15.5.|Applications close|
|15.6.|Notification of acceptance|
|5.8.|Deadline of final roster & logo submissions|  
|16.9.|Poster submitted|
|7.10.|Final architecture proposal|
|15.11.-22.11.|SCC@SC|
